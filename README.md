# NightPDF
Offline Android PDF reader, with selective night mode: black background, white text and original bitmap image colours. Day mode restores normal page colours. PDFs are never modified. Scanned pages are preserved as images. Complex masks, transparency and vector diagrams may render differently. Not validated for diagnostic use.
Open the Actions tab, select the nightpdf branch, open a successful Build NightPDF APK run and download the NightPDF-APK artifact. Unzip and install NightPDF.apk. This branch is independent of SpeedVoice main.
